# 火柴人狙击 PWA（sniper-pwa）

DaoBox 家族第 14 个应用：经典光枪狙击小游戏（方案 B 火柴人狙击，关卡结构预留方案 C 任务制）。

## 玩法

- 城市街区夜景，敌人从窗户探头或在街上跑过
- 瞄准镜瞄准（准星有呼吸晃动），点击开枪；爆头 250 分、身体 100 分，连击最高 x5
- 弹匣 5 发打完自动装填 1.8 秒（R 键提前装弹）
- 限时内击倒规定数量进入下一关，难度递增（敌人更快、探头更短、准星更晃）

## 技术

- 纯前端 Canvas 2D + PWA，零服务器对战成本；WebAudio 合成音效（零素材）
- 关卡数据结构预留 mission 字段（方案 C：只打目标/别打平民/风偏，二期）
- 进度/最高分 localStorage 存档；portal 时长体系（游客 15 分/注册 30 分）

## 部署

sniper.daobox.net.cn（阿里云 systemd **8800** + Caddy；8800 为 docs/服务器端口分配.md 排队的下一端口）。
