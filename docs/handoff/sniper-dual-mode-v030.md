### 2026-11-03 v0.4.5 声音客观排查结论 + 叫声强化 + 音效试听

- **客观证据（RMS 实测）**：AnalyserNode 挂声源实测输出波形，v0.4.4 叫声 RMS 0.309 > 枪声峰值 0.187——代码确实在发声。用户手机/iPad 听不到的最合理解释：叫声是 0.1-0.4s 短促高频滑音，被手机小喇叭 + 枪声低频"砰"掩蔽，听感上等于没有。
- **v0.4.5 改法**：叫声音量 0.4→0.65-0.72、时长约 ×1.5（惨叫 0.6s/狼嚎 0.55s/老大 0.55s+倒地双响/鸟三连叫 0.54s）；枪声 0.95→0.7、时长 -30%；叫声延迟 60→90ms。
- **菜单新增"音效试听"行**：枪声/鸟叫/惨叫/狼嚎/老大 5 个试听按钮（.sfx-row/.sfx-btn，SFX.demo），用户可在任意设备一键验证设备能否播放 WebAudio，区分"设备问题"vs"声音太弱"。
- E2E：四类目标命中+叫声振荡器 7-9 个/枪，0 报错；线上 v0.4.5 / dbsniper-v17 / game.js?v=16 确认。
- **待用户确认的三个新需求**：①手机横屏适配方案（方案 A 旋转提示 + 横屏满屏 / 方案 B CSS 强制旋转）②玩法说明 <details> 折叠 ③游戏改名建议（鹰眼狙击/黄昏狙杀/猎杀时刻/一枪封喉）。
